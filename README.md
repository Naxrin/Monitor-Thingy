# Fullscreen Monitor Switch
- switch between Fullscreen / Windowed anywhere in game
- move Geometry Dash to an other monitor in fullscreen mode for those who can afford multiple monitors.

### Keybinds
- Press the **Switch Fullscreen** keybind (`F8` by default) to switch fullscreen mode.
- Press the **Switch Monitor** keybind (`F9` by default) to move the game to the next monitor.

### Notice
- Works while fullscreen and, optionally, while windowed.
- Your current monitor is optionally remembered, so toggling fullscreen or restarting the game keeps the game there.
